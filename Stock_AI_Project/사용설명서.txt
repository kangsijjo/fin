[A. 처음에 알아둘 것]
----------------------------------------------------

이 시스템은 PC가 켜져 있고 run_scheduler.bat 가 돌고 있으면
모든 매매와 데이터 수집이 자동으로 일어납니다.

핵심 시간:
  - 매일 10:05 → 한국 매매 (모델 시그널 Top-1 자동 매수, config 의 top_n)
  - 매일 22:30 → 미국 매매 (Top-1, 2026-06-11 부터 실제 동작)
  - 매일 09:00~15:30 → 장중 보유 종목 1분마다 익절/시간청산 체크
  - 매일 06:30 → 데이터 수집
  - 매주 토 07:00 → 데이터 갭 자동 백필
  - 매주 일 07:00 → 모델 재학습
  - 토/일 → 매매·장중모니터 자동 스킵 (2026-06-11)

사용자는 보통 아무 것도 안 해도 됩니다.
다만 가끔 "잘 돌고 있나" 확인 + 가끔 비상 대응이 필요할 뿐.



[B. "잘 돌고 있나" 확인 - 매일 한 번 정도]
----------------------------------------------------

방법 1: 라이브 대시보드 (시각적, 추천)
  PowerShell 열고:

방법 2: 실시간 로그 보기 (가벼움)

방법 3: 한 줄로 잔고 + 보유 종목

[D. 비상 시 대응]
----------------------------------------------------

D-1. 한글이 깨져 보임 (PowerShell)
  PowerShell에 한 번만 붙여넣기:
    [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
    $OutputEncoding = [System.Text.Encoding]::UTF8
    $PSDefaultParameterValues['*:Encoding'] = 'UTF8'
    chcp 65001
    $env:PYTHONIOENCODING = "utf-8"

D-2. "Could not find a suitable TLS CA certificate bundle" 에러
  원인: 백신이 venv 안의 cacert.pem 을 격리함
  해결 순서:
    (1) Windows 보안 → 바이러스 및 위협 방지 → 설정 관리
        → 제외 항목 추가 → 폴더 → C:\fin\Stock_AI_Project\venv 추가
    (2) PowerShell:
        cd C:\fin\Stock_AI_Project
        .\venv\Scripts\activate
        pip install --force-reinstall certifi
    (3) 스케줄러 재시작: run_scheduler.bat

D-3. 매도가 자꾸 실패 (잔고 없음 무한 루프)
  python cleanup_orphan_positions.py
  → DB와 KIS 실제 잔고를 sync. orphan 자동 정리됨.

D-4. 스케줄러가 멈춰 있는 것 같음
  PowerShell:
    tasklist | findstr python
  → python.exe 가 없으면 죽은 것 → run_scheduler.bat 더블클릭
  → 있는데 로그가 5분 넘게 안 흐르면 → Ctrl+C 두 번 + 재시작

- 인터넷 끊김 길어지면 그 시점 작업 영구 누락

이 시스템은 "감정 배제 자동 매매 인프라" 입니다.
모델 알파(예측력) 자체는 별개로 검증 중. 신중하게.
