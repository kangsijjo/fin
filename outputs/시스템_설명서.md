> ## ★ 2026-06-28 지표 조합 탐색 (그룹 토글 + 간결성 페널티)

- 백테스트 다중전략 비교 결과, **서로 다른 메커니즘의 3전략을 병렬로 운용**하는 것이 단일 전략보다 리스크 분산 면에서 유리함이 확인됨.

## 3. 3전략 병렬 운용 — 슬롯 구조

2026-06-16부터 단일 전략(high_500d_h40_MKT)에서 **3전략 병렬 운용**으로 전면 전환.  
총 10개 슬롯을 전략별로 고정 배분하고, 각 전략의 신호로 채운다.

### 슬롯 배분

| 슬롯 | 전략 | 코드명 | 보유기간 |
|---|---|---|---|
| 1~6 (6개) | 52주 신고가 + 시장게이트 + 거래량 | `high_52w_filt` | 20 영업일 |
| 7~8 (2개) | 외국인 연속매수 + 20일 신고가 + 게이트 | `for_high20_mkt` | 20 영업일 |
| 9~10 (2개) | RSI 14일 < 30 과매도 반전 | `rsi_reversal` | 5 영업일 |

### 전략 1 — high_52w_filt (슬롯 1~6)

진입 조건 (3가지 모두 충족):
1. **52주 신고가 돌파**: 오늘 종가 > 직전 252 영업일 고가 최대값
2. **시장 강세 게이트**: 전체 종목 평균 등락률의 60일 MA > 0
3. **거래대금 필터**: 전일 거래대금 ≥ 30억 + 오늘 거래량 ≥ 20일 평균의 1.5배

청산: 진입일 포함 **20 영업일째 종가** (손절/익절 없음)

### 전략 2 — for_high20_mkt (슬롯 7~8)

진입 조건 (3가지 모두 충족):
1. **외국인 연속 순매수**: 최근 3일 연속 foreign_net > 0
2. **20일 신고가 돌파**: 오늘 종가 ≥ 직전 20 영업일 최고가
3. **시장 강세 게이트**: 동일한 60일 MA 게이트 + 거래대금 ≥ 30억

청산: 진입일 포함 **20 영업일째 종가** (손절/익절 없음)

### 전략 3 — rsi_reversal (슬롯 9~10)

진입 조건:
1. **RSI(14) < 30**: Welles Wilder 방식 RSI 기준 과매도 구간 진입
2. **거래대금 필터**: 거래대금 ≥ 10억 (모멘텀 전략보다 낮은 기준)
3. **시장 게이트 없음**: RSI 반전은 약세장에서도 단기 반등 노릴 수 있으므로 제외

청산: 진입일 포함 **5 영업일째 종가** (빠른 회전)

### 공통 제외 종목
- ETF (KODEX, TIGER, KBSTAR, KOSEF, ARIRANG, HANARO, SOL, ACE, PLUS, RISE, 1Q, WON 등)
- 우선주 (이름이 "우", "우B"로 끝나거나 "우선주" 포함)
- 스팩 (이름에 "스팩" 포함)
- 코드가 5로 시작하는 6자리 종목

### 자본 운용
- 최대 동시 보유 종목: **10개 슬롯** (전략별 한도 내에서만 채움)
- 자본 배분: 예수금 ÷ 남은 총 슬롯 수 = 종목당 투자금 (1/N 방식, 슬롯 가득 찰수록 비중 증가)
- 슬롯 초과 신호는 건너뜀 — 전략 우선순위: high_52w_filt → for_high20_mkt → rsi_reversal
- 같은 종목이 다른 전략에서 동시에 신호 → 허용 (dedup 키: signal_date+code+strategy)

### 진입 방법 (공통)
- 신호 발생일 **다음 영업일 시가**에 매수 (당일 종가 확정 후 다음날 시가 진입)
- paper_tracker는 X2 모드: 신호일 종가 × 1.02 (시간외 가정)

## 6. AI 보조 모델 — LightGBM (Stock_AI_Project)

### 역할
- 메인 전략(신고가 돌파)으로 진입하는 **종목 중에서 더 좋은 종목을 고르는 보조 도구**.
- 현재는 직접 매매에 반영하지 않음 (`USE_AI=False`).
- AI 사이징 연동은 모의 검증 수개월 후, 성과가 +3%p 이상 안정적으로 나올 때 결정.

### 학습 목표
```
"5영업일 후 +2% 이상 오를 확률"
```
- 분류 모델: 상승 확률 > 0.55 이면 매수 신호
- 섹터별로 별도 모델 학습 (반도체, 제약, IT 등)

### 26개 피처 (입력 변수)
기술적 지표:
- `ma5`, `ma20`, `ma60` — 5/20/60일 이동평균 대비 현재가 비율
- `rsi_14` — 14일 RSI
- `macd`, `macd_signal` — MACD
- `bb_upper`, `bb_lower`, `bb_pct` — 볼린저밴드 위치
- `vol_ratio_5`, `vol_ratio_20` — 거래량 평균 대비 비율
- `atr_14` — 14일 평균진폭 (변동성)
- `momentum_5`, `momentum_20` — 단기·중기 모멘텀

수급 피처:
- `foreign_net_5d`, `inst_net_5d` — 외국인·기관 5일 누적 순매수
- `credit_balance_ratio` — 신용잔고 비율
- `short_ratio` — 공매도 비율

거시 피처:
- `vix`, `nasdaq_return_5d` — 글로벌 리스크 지표
- `usd_krw_change` — 원달러 환율 변화

뉴스·공시 피처:
- `news_sentiment` — 최근 뉴스 감성 점수 (-1 ~ +1)

### 학습 파이프라인
```
백테스트 매매 내역 (results/trades_AB_*.csv)
       ↓
make_trades_history_v3.py
  → stock.db 에서 각 매매의 진입 시점 피처 추출
  → trades_history_v3.csv 생성 (매매당 26개 피처 + 레이블)
       ↓
ai_trainer_v4.py
  → LightGBM 학습 (train/test split, purge gap 5일)
  → 모델 저장: ai_data/meta_model_v4.json
  → 피처 중요도: ai_data/meta_model_v4.features.csv
```

### 모델 현황 진단 (대시보드 AI 탭)
- IC 가중치 상위 피처 (Information Coefficient)
- 피처별 NaN 비율 (데이터 채워진 정도)
- 전략 평균 성과 비교
- Paper vs 백테스트 성과 drift

### 명령어

```bash
python kiwoom_trader.py daily    # sell → buy → status 일괄
```

### 매수 로직 상세 (v2 — 전략별 슬롯 배정)
1. `paper_signals.csv` 에서 어제 신호 종목 로드 + strategy 컬럼 확인
2. `db/kiwoom/orders_*.csv` 에서 이미 매수된 종목 확인 (멱등성)
3. 현재 보유 종목의 전략별 슬롯 사용량 계산 (`count_slots_by_strategy`)
4. 전략 우선순위(`high_52w_filt → for_high20_mkt → rsi_reversal`)대로 순회:
   - 해당 전략 빈 슬롯 있으면 → 거래대금 내림차순으로 종목 선택
   - 예수금 / 총 남은 슬롯 수 = 종목당 투자금
5. 시장가(trde_tp=3)로 주문 → 주문번호 + 전략명 로그에 기록

### 매도 로직 상세 (v2 — 전략별 보유일 적용)
1. `paper_signals.csv` 에서 각 신호의 **per-row `holding_days`** 읽어옴
2. 영업일 계산: stock.db 실제 거래일 목록 기준 (달력 아님)
3. exit_idx = signal_idx + holding_days - 1 (오늘 날짜가 exit_date 이상이면 매도 대상)
4. 현재 보유 잔고에 해당 종목 있으면 시장가 매도
5. 15:21 실행 → 15:30 마감 동시호가에 체결 ≈ 종가 체결

### 주문 기록 파일
- `db/kiwoom/orders_YYYYMMDD.csv`: 당일 주문 내역
  - 컬럼: time, side(BUY/SELL), code, name, qty, price, order_type, ok(True/False), order_no, msg
- `db/kiwoom/snapshot.json`: 최신 계좌 스냅샷 (예수금, 보유잔고)
- `db/kiwoom/equity_history.csv`: 자본 히스토리 (date, time, deposit, n_positions)

### 안전장치
- `KIWOOM_ENV=prod` 이면 buy/sell 명령이 **무조건 차단**되어 조회만 허용.
- 실전 전환은 **모의 검증 수개월 후 사용자가 직접 결정** — 시스템이 자동으로 전환하지 않음.
- 파일락(`data/.kiwoom.lock`): 두 시스템이 동시에 키움 API 접근 시 충돌 방지. 5분 이상 된 stale lock은 자동 해제.

## 8. 페이퍼 트레이딩 검증 체계

### 3중 검증 구조

**레이어 1 — paper_tracker.py (X2 시간외 모드)**
- 신호 발생 다음날 **다음날 종가**를 진입가로 사용하는 "이상적" 모드
- 실제로는 시간외단일가가 아닌 모드 — 모의 서버가 미지원하여 현재는 비교 기준용
- 누적 손익, 현재 보유 포지션, 평균 수익률 추적

**레이어 2 — kiwoom_trader.py (원본 모드)**
- 실제 키움 API로 시장가 매수/매도 집행
- 09:01 시가 매수 / 15:21 마감 동시호가 매도
- 실제 체결가 기록 → 진짜 슬리피지 측정 가능

**레이어 3 — paper_audit.py (drift 감사)**
- `paper_audit_result.csv` 생성
- Paper 수익률 vs 백테스트 예측 수익률 비교
- drift가 -3%p 이상 벌어지면 경보 → 모델 재점검 필요

### paper_signals.csv 구조 (v2 — 전략·보유일 컬럼 추가)
```csv
signal_date, code, name, entry_price_close, target_exit_date, strategy, holding_days, lookback_high, market_strong
2026-06-14, 005930, 삼성전자, 75000, 2026-07-11, high_52w_filt, 20, 74200, True
2026-06-14, 000660, SK하이닉스, 150000, 2026-06-20, rsi_reversal, 5, , 
```
- `entry_price_close`: 신호일 종가 (참고용; 실제 매수는 다음날 시가)
- `target_exit_date`: holding_days 영업일 후 날짜 (전략마다 다름)
- `strategy`: 신호를 생성한 전략명 (`high_52w_filt` / `for_high20_mkt` / `rsi_reversal`)
- `holding_days`: 전략별 보유 영업일 수 (20 또는 5)
- **backward compat**: 구버전 CSV에 strategy/holding_days 컬럼 없으면 자동으로 `strategy="high_52w_filt"`, `holding_days=40` 채움 (`_migrate_signals_csv()` 자동 실행)

## 9. 팩터 스코어링 — 종목 우선순위 보조

### factor_scorer.py

신호 발생 종목들 중 어떤 종목을 먼저 매수할지 판단하는 보조 점수 시스템.

**Method A — IC 가중 팩터 점수**
- 각 피처의 IC(Information Coefficient: 피처값 vs 실제 수익률 상관계수) 계산
- 상위 IC 피처에 높은 가중치를 부여
- 현재 피처값에 가중치를 곱해 최종 팩터 점수 산출

**Method B — SHAP 기반 중요도**
- LightGBM AI 모델 학습 후 SHAP값으로 각 피처의 기여도 측정
- 모델이 "왜 이 종목을 좋게 봤는지" 설명 가능

**live_signal.py 실행 시 자동 출력**:
```
[factor_scorer] 오늘 신호 종목 팩터 점수:
  삼성전자(005930):  IC점수 0.82 | SHAP기여 +0.14
  SK하이닉스(000660): IC점수 0.74 | SHAP기여 +0.11
```

### 팩터 점수 활용 방법
- 현재: 참고용 출력만 (실제 매수 우선순위에 미반영)
- 향후: 슬롯이 꽉 찬 상황에서 점수 낮은 기존 종목을 교체하는 기준으로 활용 예정

## 15. 시스템 한계와 주의사항

### 알려진 한계

**1. 메인 전략의 약세장 미검증**
- 6년 성과에 2022년 -13.8% 포함되지만 시장 게이트가 보호.
- 장기 하락장(2007~2008년 금융위기 수준)에서의 성과는 미검증.

**2. AI 모델 알파 약함**
- LightGBM은 현재 보조 도구 — 직접 매매에 미반영.
- 섹터별 성과 편차 큼 (제약 +0.58% vs 반도체 -0.08%).
- 수수료 포함 시 사실상 0에 수렴할 가능성.

**3. 집중 리스크**
- 10 슬롯이지만 실제로는 1~3개 동시 보유가 많음.
- 한 종목 급락이 그대로 전체 성과에 반영.
- 진짜 분산은 동시 20~30 종목 필요.

**4. 무료 API 한계**
- KIS API: 외국인·기관 수급 최근 30일만 제공.
- 호출 빈도 제한 (KIS 모의 ~2 req/s).
- 진정한 OCO(One-Cancels-Other) 미지원.

**5. PC 의존성**
- PC가 꺼지면 매매 자체가 안 됨 → 잠자기 OFF 필수.
- Windows 자동 업데이트 재부팅 시 스케줄러 중단 위험.
- 해결책: 부팅 시작 프로그램에 `run_scheduler.bat` 등록.

**6. 모의투자 ≠ 실거래**
- 모의는 슬리피지·체결 지연·시장 임팩트 0.
- 실전에서는 같은 신호에 0.1~0.3% 추가 비용.

### 실전 전환 조건 (결정 기준)
1. 키움 모의투자 수개월 운영 후 paper vs 실제 체결가 drift 측정
2. AI 보조 모델의 사이징 기여가 **수개월 연속 +3%p 이상** 안정적으로 나올 때
3. 조건 달성 후 사용자가 직접 `KIWOOM_ENV=prod` 로 변경 → 실전 전환
4. 전환 후에도 일일 손실 한도(-2%) 절대 준수

기존 메인 전략(high_500d_40) 유지는 타당하나 성과 기대치를 현실적으로 낮춰야 함. 추가로 다음 두 가지를 병행 운용하는 복합 포트폴리오 검토 가치 있음:

1. **RSI 반전 전략** — 슬롯 2~3개 별도 배정, 빠른 회전 (5일)
2. **for_high20_mkt** — 외국인 수급 확인 후 20일 신고가 돌파, 시장 게이트 포함

두 전략 모두 현행 모의투자와 병렬로 페이퍼 트레이딩 후 drift 검증 권장.

## 17. 3전략 병렬 운용 — 전략 상세 및 결정 배경

### 전환 결정 배경 (2026-06-16)

2019~2025 전 종목 백테스트 비교(36개 전략) 결과, 단일 전략 집중보다 **서로 다른 메커니즘**의 전략을 슬롯으로 나눠 병렬 운용하는 것이 리스크 분산에 유리함을 확인.

- 기존 메인 전략(`high_500d_40`)은 2026 이상현상 제외 시 avg_net +0.27%로 기대치 크게 낮아짐.
- `high_52w_filt`(52주 기준)이 동 기간 avg_net +1.05%로 더 안정적.
- `rsi_reversal`은 Sharpe 3.17 — 모든 전략 중 가장 안정적인 알파.
- `for_high20_mkt`는 수급(외국인) + 가격 신호를 결합, 두 전략과 상관성 낮음.

세 전략은 **진입 메커니즘이 다르기** 때문에 상관성이 낮고, 한 전략이 약세인 시장 환경에서 다른 전략이 보완하는 역할을 한다.

### 슬롯 수 배분 이유

| 전략 | 슬롯 | 이유 |
|---|---|---|
| high_52w_filt | 6 | 신호 빈도 높음, 메인 전략으로 자본 대부분 배치 |
| for_high20_mkt | 2 | 수급 데이터 품질에 의존적 → 소규모 검증 먼저 |
| rsi_reversal | 2 | 5일 빠른 회전 → 슬롯 2개만으로도 연간 회전수 충분 |
